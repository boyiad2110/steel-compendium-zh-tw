## 驗證

- 前輪程式原因：Browse 自連結經 MkDocs 改為 `./` 後缺精確適配；Read 最近子標題及已翻譯標題切斷範圍；部分短句／卡片只查 segment，漏掉已核准 label。既有迴歸測試現涵蓋真實來源、`./`、38 段故事、7 項 Read 特性及靜態／動態卡。
- 本輪原因：原 8000 實際 HTTP 仍送出舊漏譯內容，雖然 repo 位於修正版；查得兩組殘留 MkDocs serve 程序。先前只交重啟指令而未核對服務回應，導致交付版本未落實。已停止這兩組 repo 程序，改以本輪驗證產物作唯一固定預覽，8 個回應逐位元組比對一致。
- 本輪新增缺口：Read 總覽僅矮人有「名稱＋摘要」接線，未接幻林精靈與龍騎士同版核准摘要；完整公式的 `or` 亦未進快照。已接入既有摘要並保留全部原連結；依先前審稿核准補 SC Master 公式，讀回後只新增 1 筆核准快照紀錄，沒有修改 Book Master 或在程式寫死譯文。
- 回歸證據：新總覽測試在舊程式對龍騎士／幻林精靈兩列失敗、修正後通過；完整卡測試確認公式中文、兩個原連結及 inline 結構保留。完整 `.venv\Scripts\python.exe scripts/l10n/verify.py` 退出碼 0：Python 68 項測試 15.23 秒、JavaScript 0.73 秒、build 207.8 秒、artifacts 1.7 秒；`verification.json` 與本輪 `verification-*.log` 一致。
- Agent 實測：Edge、桌面、明亮模式；每種受影響模板均檢查代表頁，含站內靜態／動態卡跳轉。使用者已另行明確驗收通過；匯出、手機及深色模式不因此補記成 Agent 已測。
