## B05 錯誤改善與回歸防線

1. **自連結與故事連結：**測試套用 MkDocs hook 前的正式 `href="./"` 輸入；實際命中及翻譯後逐一比對原連結目的地。`_linked_target` 對目標譯文中已存在的中文錨點以精確標籤配對，沿用來源 href；複數／重複錨點逐一消耗，不移除連結。
2. **Read 範圍：**族裔區段以 SCC／章節界線辨識，測試章首總覽、名稱＋摘要、故事、姓名、測量及每項特性；並斷言不會將高等精靈核准內容套用到幻林精靈區段或後續族裔。
3. **短句與完整欄位：**從實際 hook／UI 命中來源檢查總覽摘要組合、特性短句、`One creature` 等完整欄位、成本和標籤；不能只以中文名稱判定卡片完成。
4. **完整性：**建立明確預期清單並逐項檢查 58 筆高等精靈族裔紀錄、9 筆 UI；故事固定 32 段，Browse／Read 比對段落和連結，特性／索引／動態 UI 另有斷言。
5. **結構：**保留 inline 標記、粗體數字、公式與 href；連結適配只在精確核准紀錄與目的地上執行。未新增卡片段落包裝；異常以 DOM／computed style 比較後處理。
6. **預覽交付：**本輪使用唯一 Agent 管理服務，需記錄 PID、命令、工作目錄、URL、建置版本，並讀取實際 HTTP 回應及瀏覽器確認。固定 `site/` 預覽不會自動重建；若瀏覽器或沙箱存取受限，明列限制，不宣稱已驗證。
