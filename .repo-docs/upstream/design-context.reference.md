## Design Context

### Users
- **Primary audience**: Draw Steel TTRPG players and Game Masters
- **Use cases**: All valid — GMs prepping sessions on desktop, players referencing rules mid-game on phones, character builders browsing options on tablets
- **Job to be done**: Quickly find and read specific rules, abilities, monsters, and character options from the Draw Steel ruleset

### Brand Personality
- **Three words**: Reliable, Authoritative, Practical
- **Emotional goals**: Epic fantasy authority meets practical reference utility — the site should feel like a trusted, well-crafted tome, not a wiki or corporate tool
- **Tone**: Confident and clear, like a well-designed game book — not playful, not sterile

### Aesthetic Direction
- **Visual tone**: Epic fantasy with dark fantasy undertones — inspired by MCDM's Draw Steel art direction
- **Typography**: Body is Berlingske Slab, the official Draw Steel PDF's own body face (licensed from Playtype and self-hosted — SC-320; Zilla Slab is its fallback and a preference option). Headings are free Google Fonts stand-ins for their PDF counterparts — Cinzel for display headings (Beaufort), Petrona for subheads (Newzald) — keep these as defaults but allow user customization via preferences
- **Color palette**: Current Material for MkDocs defaults feel generic — needs a unique palette that reflects the Steel Compendium brand and Draw Steel's visual identity
- **Theme**: Dark mode preferred default; light mode available. Goal: expand preferences to allow full theme customization
- **Anti-references**: Must NOT look like Microsoft products or SharePoint sites
- **Navigation priority**: Clean, practical navigation above all else

### Design Principles
1. **Navigation is king** — Every design decision should make finding information faster and easier
2. **Authoritative tome, not a wiki** — The site should feel like a premium, well-organized reference book, not a crowdsourced wiki or corporate intranet
3. **Epic but functional** — Fantasy atmosphere should enhance, never impede, the practical reference function
4. **Distinctive identity** — Avoid generic Material Design defaults; the Steel Compendium should be visually recognizable
5. **Respect user agency** — Preferences system lets users customize fonts, width, theme to their needs
